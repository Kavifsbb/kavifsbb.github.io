# Site Web de Kavi Freestyle Basket

Site web professionnel pour Kavi, freestyler basket professionnel et membre de l'équipe Vagabond Crew International.

## Structure du Projet

```
.
├── index.html          # Page principale du site
├── css/
│   └── global.css      # Styles globaux
├── js/
│   └── main.js         # Scripts JavaScript
└── assets/            # Dossier pour les médias
    ├── images/        # Images du site
    └── videos/        # Vidéos du site
```

## Technologies Utilisées

- HTML5
- CSS3 (avec variables CSS pour la personnalisation)
- JavaScript (Vanilla)
- Font Awesome pour les icônes
- Google Fonts (Bebas Neue, Montserrat, Roboto)

## Fonctionnalités

- Design responsive
- Animations au scroll
- Menu mobile
- Formulaire de contact
- Galerie de services
- Section statistiques animée
- Intégration vidéo en arrière-plan

## Installation

1. Clonez ce dépôt
2. Ouvrez `index.html` dans votre navigateur

## Contenu à Ajouter

Pour finaliser le site, vous devrez ajouter :

1. Les images des services dans `assets/images/`
2. Une vidéo de background dans `assets/videos/`
3. Les photos de la galerie
4. Le contenu réel des sections
